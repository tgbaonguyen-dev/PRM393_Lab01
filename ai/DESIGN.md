# UI Design

## Status

The design, brand colors, fonts, and wireframes have not been finalized. This file records UI decisions after team agreement; it does not request immediate implementation.

## Proposed scope

- Teachers use personal computers to manage classes and schedules and display QR codes.
- Students use mobile browsers to sign in and check in.
- Proposed UI direction: responsive Flutter Material 3.
